Chapter 1 Speedrunning Guide

Color Key

This guide will be utilizing a color key. This is just for organization and easy viewing. Here it is:

  • Location / Interactable
  • Choice
  • ACT / Spare / Magic
  • Fight
  • Defend
  • Item or Equipping
  • Enemy
  • Text of Importance
  • Strat Name

Additionally, there also exists the [TP], [TR], [AB] and [1.09] tags. These will be used for whenever there is a difference between the Any%, True Pacifist, True Reset, All Bosses, and 1.09 routes respectively. If you are doing any of these routes, do these things instead of what Any% does. If there is no tag for the battle, you are supposed to do the same thing in these categories and Any%.

There is also a video guide by the former Chapter 1 Any% world record holder ashmichda. Note this is only Any%, but it is still very good for people getting into Chapter 1 speedrunning.

Set Up

In all non-1.09 categories, most top players play on SURVEY_PROGRAM. In 1.09 categories (or if you want to save a few seconds but have a considerably more difficult run), play on Demo version 1.09.

There’s not much to address. Complete the game once previously. Make sure you have an empty save file and set the text to Japanese.

For this run, you will be holding down Ctrl and Shift for all of it. Setting up sticky keys to toggle them (click here for the section in ashmichda’s guide) or using a weight to hold them down is recommended.

If you find yourself in need of a save, check the speedrun.com resources page for Deltarune. There should be some there.

For practice, you can download the keucher mod, which has lots of capabilities including savestates, a boss practice mode and debug features. A guide for setting up Keucher mod can be found here.

Make sure your monitor’s refresh rate is set to 60 or 120Hz if you play on SURVEY_PROGRAM, otherwise you will lose a frame on every single room transition. You can change your monitor’s refresh rate by going into Settings -> Display -> Advanced Display Settings.

Mechanics

This short section will outline some of the mechanics behind the speedrun.

Running

There’s not much to say about running besides bumping into things. Bumping into things will make you lose your momentum and have to spend a tiny amount of time building up speed again. In some cases this can cause you to fail an encounter skip. Be careful.

Text Skipping

Once you have the wrist protector, you can hold C or CTRL to skip text. However, that’s not all. The wrist protector skips text at a speed of 15 textboxes per second, but if you mash Z and Enter on top of it you can skip text at up to 30 textboxes per second, so you will want to mash all of the textboxes in the run.

Tension Points (TP) and grazing attacks

Obviously grazing by attacks will cause you to build TP, but what isn’t explicitly stated is that it also speeds up some attacks. Note that I said “some.” You can find a guide on what attacks are and aren’t sped up here.

Rude and Red Buster extra damage

This fact isn’t well known which is why I have this listed here. Spam Z and Enter during the Rude and Red Buster animations and you’ll do 30 more damage. Don’t worry about it too much, as long as you press Z or Enter within the general attack animation you’ll get it.

Holding down Ctrl and Shift

I talked about holding down Ctrl and Shift in the set up, and I’ll explain it here. Shift will make you run and Ctrl will auto-skip text once you have the Wrist Protector. It is 100% safe to hold them both down for the entire duration of the run. Keep these held down the whole run, from start to finish.

Auto-Run

Auto-run is an option that makes running the default, and pressing X or Shift will slow you down to a walk. Not only that, it also makes you get to running speed faster, which saves a frame in every room where you have to build up running speed at the start. It also allows for ARMS and ARSS on Demo. However, mashing over the Wrist Protector can only be done while X or Shift is held, which means that you must press X or Shift when a series of textboxes start, and release it before you start running again. This makes auto-run very difficult to utilize for an entire run, and so it's only really used to perform ARSS.

Demo differences

The Chapter 1&2 Demo Version is required to be used in 1.09 and All Chapters categories, and is slightly faster but considerably more difficult to run on in Chapter 1-only categories. It has a few differences to SURVEY_PROGRAM. Notably, encounter skips are harder and the Wrist Protector is not needed. In spots where this makes a significant difference, Demo specific strategies will be explained. Additionally, Demo has two unique tricks, ARMS and ARSS.
